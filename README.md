# Respect Land

منصة عربية لاكتشاف صنّاع المحتوى — مجتمع يمنحهم المساحة التي يستحقونها.

## المميزات

- صفحة رئيسية ديناميكية: أبطال الأسبوع، الأكثر تداولًا، أحدث المنضمين، التصنيفات.
- دليل صنّاع المحتوى مع بحث وتصفية حسب التصنيف.
- متصدرون وترتيب صنّاع المحتوى.
- أقسام: تطبيق انضمام، مفضلة، آخر المشاهدة.
- لوحة تحكم إدارية كاملة (تحليلات، إدارة صنّاع المحتوى والتصنيفات والطلبات والإعدادات، تصدير/استيراد البيانات، سجل النشاط).
- عربي بالكامل (RTL) مع دعم كامل للأوضاع الحديثة.

## التشغيل محليًا

شغّل `run.bat` (على Windows) — يفحص Node.js، يثبّت الحزم، يجهّز قاعدة البيانات، ويشغّل الخادم ويفتح المتصفح:

```
http://localhost:3000
```

دخول لوحة التحكم (<http://localhost:3000/login>):

```
admin@respect.land / admin123
```

أو يدويًا:

```bash
npm install
npx prisma db push
npm run db:seed   # بيانات تجريبية
npm run dev
```

## النشر على Vercel

1. ادفع الكود إلى GitHub ثم استيراد الريبو في [vercel.new](https://vercel.new).
2. في إعدادات المشروع أضف المتغيرات:
   - `DATABASE_URL=file:./dev.db`
   - `AUTH_SECRET` — أنشئ واحدة سرية من <https://generate-secret.vercel.app>
   - `AUTH_TRUST_HOST=true`
3. الأدمن المبدئي: `admin@respect.land / admin123`.

> **ملحوظة مهمة:** الموقع مخزّن على SQLite وملف قاعدة البيانات `prisma/dev.db` مرفوع مع الكود حتى يعمل على Vercel بدون حساب DB خارجي. هذا يعني أن أي تعديل على البيانات يُفقد عند إعادة النشر أو برودة الخادم (cold start) — لا تستخدمه لتخزين بيانات دائمة. للاستخدام الإنتاجي رحّل إلى قاعدة بيانات دائمة (مثل Postgres من Neon أو Supabase — مجانية).
